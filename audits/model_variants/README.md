# Model-variant / convergence provenance (S6, S11 and Table S15)

The published v1.0.0 archive contains the current symmetric common-price pilot,
but did not include executable provenance for the **five first-period
convergence-screen cases (Table S6)** and **historical Gauss–Seidel comparison
variants (S11/Table S15)**. These additive scripts fill that gap.
They do not alter `pilot16.py`, the archived model, or any control trajectory.

Run from the repository root:

```bash
python audits/model_variants/reproduce_S6.py
python audits/model_variants/reproduce_S11.py
```

For the twelve cyclic/reversed update orders on the sparse direct-action map:

```bash
python audits/model_variants/reproduce_S11.py --sparse-order-sweep
python audits/model_variants/reproduce_S11.py --dense-order-spotcheck
```

`reproduce_S6.py` calls the original published `coordinate` routine on the
first horizon. The unsuccessful (tau,gamma,omega)=(20,200,0.6) case is retained
as a negative convergence test, not hidden.

`legacy_sequential.py` preserves the previous Gauss–Seidel residual-budget
implementation. `reproduce_S11.py` gives it the same smooth activation as v16
without changing any coefficient or objective weight. It reconstructs the dense
and sparse sequential scenarios. The sparse common-price row is read from the
unchanged frozen v1.0.0 nominal reference, whose original executable solver is
in the repository root. The scripts do **not** claim that the historical
sequential procedure was the final distributed algorithm.

The full sparse 12-order experiment is stored. Dense-map order sensitivity was not exhaustively regenerated by this release;
`--dense-order-spotcheck` records two selected orders. The cyclic-shift case
places about 0.445 cumulative control on the regulator, so the historical
summary saying dense regulatory allocation ranges from 0.05 to 0.30 across
update orders is **not valid for this tested set**. Do not claim such a global
range without a precisely specified sampling set. This numerical caveat does
not affect the nominal Table S15 values or the final common-price model. All returned values depend on SciPy and floating
point; the validators allow small numerical variation.
