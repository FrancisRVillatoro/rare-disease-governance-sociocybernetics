# v1.0.0 — frozen reproducibility release

Initial public reproducibility release for the computational workflows associated with:

> **A socio-cybernetic architecture for rare-disease governance based on social systems theory**

This release contains only code, frozen machine-readable numerical results, dependency specifications, and reproducibility documentation. It does not contain manuscript or journal-submission files.

The frozen workflow includes:

- symmetric shadow-price distributed coordination;
- static and centralised comparator calculations;
- deterministic sensitivity and algorithmic audit tests;
- paired 100-run stochastic sensitivity with re-optimisation;
- figure regeneration and numerical verification.

The release is distributed under the MIT License. Figure binaries and per-replicate Monte Carlo records are regenerated locally and are not archived as frozen files.
